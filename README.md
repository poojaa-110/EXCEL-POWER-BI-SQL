# Employee Workforce Analytics

## 📊 Project Overview

Employee Workforce Analytics is a data analytics project designed to understand workforce structure, employee attendance, salary distribution, productivity, performance, and attrition risk.

The project uses **SQL for data analysis** and **Power BI for visualization and dashboarding**.

## 🎯 Project Analysis

### 👥 Workforce Analysis

This analysis provides an overview of the organization's workforce based on:

- Total employees
- Department-wise employees
- Gender distribution
- City-wise employees
- Employment type
- Salary bands
- Tenure categories
- Average age and experience

### 💰 Salary & Payroll Analysis

The project analyzes the organization's salary structure through:

- Total payroll
- Average salary
- Highest and lowest salary
- Department-wise average salary
- Department-wise payroll
- Highest-paid employees
- Top 10 highest-paid employees

### 🕒 Attendance Analysis

Employee attendance and working patterns are analyzed using:

- Overall attendance percentage
- Present and absent days
- Attendance status
- Average working hours
- Department-wise attendance
- Department-wise overtime
- Employees with highest overtime
- Leave type distribution

### 📈 Performance Analysis

The performance analysis focuses on:

- Average productivity by department
- Top productive employees
- Average manager rating by department
- Performance category distribution
- Department with highest productivity

### ⚠️ Attrition Risk Analysis

The project also analyzes employee attrition risk by looking at:

- Attrition risk distribution
- Employees identified with high attrition risk
- Relationship between workforce and performance-related metrics

## 📊 Power BI Dashboard

The Power BI dashboard presents the analysis through three main sections:

- **Executive Overview** – Workforce and salary overview
- **Attendance Analysis** – Attendance, working hours, overtime, and leave analysis
- **Performance Analysis** – Productivity, manager ratings, performance categories, and attrition risk

## 🔍 Key Questions Answered

- How is the workforce distributed across departments and locations?
- What is the overall salary and payroll structure?
- Which departments have higher payroll and average salaries?
- What is the overall employee attendance level?
- Which departments have higher overtime?
- Which employees have higher productivity?
- How does performance vary across departments?
- How are employees distributed by performance category?
- How is attrition risk distributed among employees?
